# AT32M412 + MP6540H + MA600A 有感 FOC 控制器开发记录

创建日期：2026-06-11  
项目路径：`E:\WorkSpaces\2_电机驱动\MPS_MotorDriver`  
参考资料路径：`E:\WorkSpaces\01_ChipInfomation\AT32\M412\AT32M412_LV_MC_Library_Porject_V2.1.5`  
当前目标：开发一套基于 AT32M412、MP6540H、MA600A 的无刷有感 FOC 控制器，支持开环控制、电流环、速度环、角度环，后续通过 CAN 接收控制指令。

## 1. 项目目标

本项目以当前 Workbench 生成工程为基础，参考 AT 官方 `pmsm_foc_magnetic_encoder` 电机库示例，构建一套可维护、可移植的 BLDC/PMSM 有感 FOC 固件。控制对象为三相无刷电机，功率级为 MP6540H，位置反馈为 MA600A 磁编码器，主控为 AT32M412。

核心功能目标：

- 完成三相互补 PWM 输出、死区、刹车/保护输入和安全默认态。
- 完成 MA600A 角度读取、零点校准、机械角到电角度转换。
- 完成低风险开环电角度旋转控制。
- 完成 ADC 同步电流采样和相电流重构。
- 完成 Id/Iq 电流环。
- 完成速度估算和速度环。
- 完成角度环/位置环。
- 完成过流、欠压、过压、堵转、编码器异常、驱动异常等保护。
- 后续通过 CAN 接收控制模式、目标电流、目标速度、目标角度和参数配置。

非目标：

- 不直接完整移植 VESC。
- 不把 AT 官方 demo 原样合并进 Workbench 生成目录。
- 不在 Workbench 自动生成文件中写核心业务逻辑。
- 初期不追求 VESC Tool 兼容和复杂在线参数系统。

## 2. 参考架构判断

AT 官方电机库示例结构：

- `mclib/`：电机控制通用库，包含 FOC、PID、电流采样、编码器、状态机和通信协议相关代码。
- `at32m412_lv_motor_ev/at32m412/pmsm_foc_magnetic_encoder/`：M412 低压电机板磁编码器 FOC demo。
- `mc_hwio.c`：PWM、ADC、DMA、OPA、CMP、UART、LED、输入捕获等硬件初始化。
- `mc_isr.c`：PWM 周期中断、电流采样中断、速度环中断、SysTick 周期任务。
- `motor_control_drive_param.h`：电机参数、采样方式、控制模式、保护阈值、PID 默认值。
- `mc_hwio_m412_lv_v1_0.h`：M412 LV demo 板的引脚和外设映射。

采用策略：

- AT 官方库作为算法和时序参考，优先借鉴 `pmsm_foc_magnetic_encoder`。
- 当前工程保持自己的目录和构建系统。
- 官方 `mclib` 可先以第三方库方式引入，后续再决定是继续使用还是替换为自研轻量 FOC。
- MA600A 驱动保持独立，不写死到 AT 官方 AS5047P/TLE5012B 驱动框架中。

## 3. 推荐工程分层

计划形成如下工程边界：

```text
app/
  motor_app.c              # 电机应用入口，处理启停、模式、目标值、状态上报
  command_router.c         # 后续 CAN 指令分发
  fault_manager.c          # 故障锁存、清除、降级和保护状态

motor/
  motor_control.c          # 统一控制接口：init/start/stop/set_target/tick
  foc_core.c               # FOC 核心或 AT mclib 适配层
  current_loop.c           # Id/Iq 电流环
  speed_loop.c             # 速度估算与速度环
  position_loop.c          # 角度/位置环
  current_sense.c          # 电流采样数据处理
  position_sensor.c        # 编码器抽象接口

drivers/
  sensors/ma600a/          # MA600A 协议层，尽量平台无关
  motor_driver/mp6540h/    # MP6540H 使能、故障、保护接口
  can/                     # CAN 驱动适配和协议帧收发

platform/
  at32/common/             # AT32 通用外设包装
  at32/m412/               # AT32M412 外设实现
  boards/mps_motor_driver/ # 本板 PWM、ADC、SPI、CAN、GPIO、保护引脚映射

third_party/
  artery/mclib/            # AT 官方电机库，尽量不修改
  artery/drivers/          # AT32 标准外设库
  artery/cmsis/            # CMSIS

generated/
  at32_workbench/          # Workbench 生成代码，允许重生成
```

当前仓库暂不强行一次性改成上述结构。实际开发采用渐进迁移：先在现有 `project/`、`middlewares/`、`cmake/` 基础上增加边界清晰的新模块，等开环和电流采样稳定后再整理目录。

## 4. 开发阶段计划

### 阶段 0：基线整理与安全约束

目标：让项目具备可持续开发的基本条件。

任务：

- 固定当前可编译基线，记录工具链、Keil/AT Workbench/CMake 状态。
- 修复或记录当前构建警告和 CMake 引用已删除文件的问题。
- 明确 MP6540H 使能脚、故障脚、PWM 输入默认态。
- 明确 MA600A SPI2 引脚、CS 引脚、电源和安装方向。
- 建立开发记录、进度记录、调试记录模板。

完成标准：

- `CLAUDE.md` 和本文档存在，并能指导中断后的智能体继续工作。
- 新增或更新调试记录模板。
- 明确哪些文件允许自动生成覆盖，哪些文件禁止写业务逻辑。

### 阶段 1：硬件 Bring-up

目标：确认 MCU、MA600A、MP6540H 和基础外设独立工作。

任务：

- 限流电源上电，记录输入电压、静态电流、板上电源轨。
- 下载最小固件，验证时钟、SysTick、GPIO、调试串口或日志输出。
- 验证 MA600A SPI 读角度，记录原始角度连续性、零点设置、旋转方向。
- 验证 MP6540H 禁用态和故障脚状态。
- 验证三相 PWM 引脚在使能前为安全状态。

完成标准：

- MA600A 原始角度读数稳定且随转子连续变化。
- MP6540H 未使能时电机无异常电流。
- 三相 PWM 引脚逻辑和预期一致。

### 阶段 2：PWM 与开环控制

目标：在低电压、限流条件下让电机可控开环旋转。

任务：

- 参考 AT 官方 `tmr_pwm_init()`，配置 TMR1 中心对齐三相互补 PWM。
- 配置死区、主输出使能、刹车输入和安全停机。
- 实现基础 SVPWM 或六步/正弦开环验证路径。
- 建立电角度递增器，支持目标开环速度、目标电压幅值。
- 验证相序、旋转方向、占空比限幅和停机行为。

完成标准：

- 电机能在低占空比下平稳开环旋转。
- 停机后 PWM 输出进入安全状态。
- 相序、方向和 MA600A 角度方向关系被记录。

### 阶段 3：ADC 同步采样与电流反馈

目标：建立 FOC 所需电流反馈链路。

任务：

- 参考 AT 官方 `adc_preempt_config()` 和 `ADC_SHUNT_SAMP_READY_IRQ()`。
- 根据当前硬件确认采样方式：两电阻、三电阻或母线/Rds(on) 采样。
- 配置 TMR1 CH4 或等效事件触发 ADC 注入/抢占采样。
- 完成零电流偏置校准。
- 完成相电流方向、比例系数、单位换算验证。
- 用示波器确认 ADC 采样点处于 PWM 噪声较低窗口。

完成标准：

- 空载零电流偏置稳定。
- 手动给小电流时采样方向和比例合理。
- 电流采样中断周期稳定，不影响 PWM 更新。

### 阶段 4：MA600A 有感角度闭环准备

目标：得到可用于 Park 变换的电角度。

任务：

- 建立 `position_sensor` 抽象，底层接入 MA600A。
- 实现机械角、零点偏移、方向、极对数到电角度的转换。
- 实现编码器对齐流程：固定 d/q 轴电压，记录电角度零点。
- 实现角度异常检测：读数失败、跳变过大、超时。
- 决定 MA600A 读取调度：初期可轮询，后续评估 SPI DMA/中断。

完成标准：

- 电角度与电机实际相位关系正确。
- 编码器零点可重复标定。
- 读角失败时控制器能停机并上报故障。

### 阶段 5：电流环控制

目标：完成 Id/Iq 闭环控制。

任务：

- 实现 Clarke/Park、反 Park、SVPWM 数据流。
- 实现 Id/Iq PI 控制器、积分限幅、输出电压圆限幅。
- 初始目标设置为 `Id=0`，`Iq` 小电流限幅。
- 在低电压限流条件下验证力矩方向、电流响应和稳定性。
- 建立电流环调参记录表。

完成标准：

- 给定小 `Iq` 时电机产生可控力矩。
- `Id` 能收敛到目标附近。
- 电流环不会出现持续振荡或失控升流。

### 阶段 6：速度环控制

目标：完成速度目标控制。

任务：

- 基于 MA600A 角度差分实现速度估算。
- 增加速度滤波和低速死区策略。
- 速度环输出 `Iq_ref`，受最大电流和保护状态限制。
- 实现加减速斜坡，避免目标突变冲击。
- 记录不同速度、负载、PID 参数下的响应。

完成标准：

- 电机可按目标速度稳定运行。
- 加减速过程无明显失控和过流。
- 速度环参数和测试数据写入调试记录。

### 阶段 7：角度环/位置环控制

目标：完成目标角度控制。

任务：

- 实现角度误差计算，处理 0/360 度跨越。
- 角度环输出速度目标或 `Iq_ref`，优先采用位置环到速度环的级联结构。
- 增加目标角速度限制、位置误差限幅、堵转保护。
- 验证阶跃角度、往复角度、保持力矩。
- 记录超调、稳态误差、响应时间和异常现象。

完成标准：

- 目标角度可重复到达。
- 保持位置时无明显抖动或过热。
- 堵转或传感器异常时能保护停机。

### 阶段 8：CAN 指令控制

目标：通过 CAN 控制电机模式和目标值。

任务：

- 定义 CAN 基础协议：节点 ID、命令 ID、数据格式、心跳、故障帧。
- 支持命令：使能、停机、清故障、设置控制模式、设置电流、设置速度、设置角度、读取状态。
- 增加 CAN 超时保护，超时进入安全停机。
- 增加状态上报：母线电压、相电流、速度、角度、温度、故障码。
- 编写上位机或 CAN 调试工具操作记录。

完成标准：

- CAN 能稳定控制启停和目标值。
- 通信超时能安全停机。
- 控制帧和状态帧格式记录在本文档或独立协议文档中。

### 阶段 9：保护、参数与发布整理

目标：形成可演示、可维护的固件版本。

任务：

- 完善故障码和故障锁存机制。
- 增加参数默认值、参数边界检查、必要的掉电保存方案。
- 整理编译说明、烧录说明、硬件连接说明。
- 形成开环、电流环、速度环、角度环测试报告。
- 汇总已知问题和下一版计划。

完成标准：

- 固件具备安全启动、运行、停机、故障保护流程。
- 文档能支持新智能体或开发者接手。
- 演示流程可复现。

## 8. CAN 协议初稿

初期 CAN 协议先保持简单，后续根据调试工具再扩展。

| 命令 | 方向 | 数据 | 说明 |
| --- | --- | --- | --- |
| `0x01` | 主机到节点 | enable: u8 | 0 停机，1 使能 |
| `0x02` | 主机到节点 | mode: u8 | 0 开环，1 电流，2 速度，3 角度 |
| `0x03` | 主机到节点 | iq_mA: i32 | 设置 q 轴目标电流 |
| `0x04` | 主机到节点 | rpm: i32 | 设置目标速度 |
| `0x05` | 主机到节点 | angle_mdeg: i32 | 设置目标角度，单位 0.001 度 |
| `0x06` | 主机到节点 | none | 清除可恢复故障 |
| `0x81` | 节点到主机 | state, fault, mode | 状态帧 |
| `0x82` | 节点到主机 | vbus_mV, iq_mA | 电压电流反馈 |
| `0x83` | 节点到主机 | rpm, angle_mdeg | 速度角度反馈 |

安全策略：

- 收到使能前，PWM 必须保持关闭。
- CAN 控制模式下超过设定周期未收到有效指令，进入安全停机。
- 故障锁存后需要显式清故障，且硬件故障条件消失后才允许重新使能。
