# Stage 5 全象限电流采样与重构设计

- 日期：2026-07-14
- 状态：已确认，待实施计划
- 适用分支：`hw/v2-coaxial-encoder`
- 相关提交：`44372d4`、`56e34e4`、`55171ba`

## 1. 背景与根因

当前三相电流由 MP6540H 的 SOA/SOB/SOC 输出采集。依据器件数据手册，SOx 能双向表示电流，但只在对应低侧 MOSFET 导通时反映该相电流。现有实现使用固定的 TMR1 CH4 上升沿触发三路 ADC 注入转换，并把三路结果无条件送入 Clarke/Park 与电流 PI。

因此问题不是“只能测正电流”，而是固定采样时刻并不能保证三个低侧管同时拥有足够的导通和建立时间。某一路落入高侧导通区或开关过渡区时，该相 SOx 失效；无效值仍被当成真实相电流参与变换，最终表现为部分象限可闭环、反向较大电流时 `id`/`iq` 异常，以及速度环复用该反馈后不稳定。

近期三次改动中：

- `44372d4` 将采样触发移入可观测窗口，但仍是单一固定时刻，未判定各相样本有效性。
- `56e34e4` 修复了母线电压读取与保护误触发，不改变相电流反馈的可用性。
- `55171ba` 增加速度环，复用了现有电流环，因此暴露问题但不是根因。

## 2. 目标

1. 在不修改硬件的条件下，使正、反电流命令都使用有效的三相电流反馈闭环。
2. 首版采用固定靠近周期顶部的单次三相采样，通过占空比判定有效相，并用 `Ia + Ib + Ic = 0` 重构缺失相。
3. 将电流命令限制为 `-1.5 A` 至 `+1.5 A`。该限制用于保护尚未确认最大能力的电机，不代表采样算法只能工作到 1.5 A。
4. 先完成 `±50/100/200/500 mA` 全象限台架验收，再人工逐级扩大到 `±1.5 A`。
5. 提供足够诊断量，能区分电流误差、采样窗口不足、PI 饱和和保护动作。

## 3. 非目标与约束

- 不修改功率板、电流检测电路或 MP6540H 外围。
- 首版不实现逐周期动态 CH4、不实现双边沿/双触发 DMA。
- 不在 FOC ISR 中恢复 VBUS 普通转换。
- 修复采样有效性前不重新整定电流 PI。
- 电流环通过 `±500 mA` 验收前，不扩大速度环测试范围。
- MP6540H 约 13 A 的硬件过流仅作为末级保护，不能替代电机级软件限流。

## 4. 方案比较

### 4.1 固定顶部采样 + 有效性判定 + 单相重构（采用）

优点是改动范围可控、时序容易示波器验证，且与官方三电阻采样库“丢弃不可观测相、用另外两相重构”的做法一致。只要同一采样帧至少有两相有效，即可得到完整三相反馈。

### 4.2 逐周期动态调整 CH4（暂不采用）

可以扩大有效窗口，但必须保证触发比较值、PWM 预装载值和 ADC 数据严格按同一周期配对。当前阶段引入的缓冲和竞态风险高于收益。

### 4.3 双边沿或双触发 DMA（暂不采用）

覆盖能力最好，但需要改变 ADC/DMA 数据组织、时序选择和异常处理。只有固定顶部方案在目标工况中持续无法获得两相有效样本时，才升级到该方案。

## 5. 总体架构

### 5.1 模块职责

- `motor_pwm_at32m412`：配置采样触发时刻；维护与 ADC 样本对应的“已生效占空比”快照。
- `current_sense_at32m412`：读取三路 ADC 原始值，完成零点和比例换算，不自行假定样本有效。
- 新增 `current_reconstruction`：纯算法模块，依据已生效占空比、采样时刻和消隐门槛生成有效掩码，选择两相并重构第三相。
- `motor_control_isr`：消费有效的重构结果；无效帧时冻结 PI，并执行连续无效帧保护。
- `motor_shell`：输出采样诊断量和保护状态。

### 5.2 数据流

```text
TMR1 CH4 触发 ADC
        |
        v
三相原始 ADC -> 零点/比例换算 -> 有效窗口判定 -> 两相选择/第三相重构
                                                    |
                         有效帧 --------------------+--> Clarke/Park -> 电流 PI
                         无效帧 ------------------------> PI 冻结/计数/故障
```

### 5.3 PWM 周期对齐

这是实现中的强制约束。TMR1 比较寄存器使用预装载时，当前 ADC 样本对应的是本周期已经生效的 CCR，而不是 ISR 刚计算并写入的下一周期 CCR。

PWM 驱动维护双缓冲状态：

- `active_duty`：当前 PWM 周期实际生效的三相占空比。
- `next_duty`：本次 ISR 写入、等待下个更新事件生效的三相占空比。
- `sampled_duty`：在更新边界保存的上一 `active_duty`，与刚完成的 ADC 注入样本配对。

更新事件处先保存 `sampled_duty = active_duty`，再将 `next_duty` 晋升为新的 `active_duty`。控制算法必须使用 `sampled_duty` 计算有效性。该状态转换需通过单元测试和示波器同时确认。

## 6. 采样时序与有效性

### 6.1 初始参数

当前 PWM 周期计数 `ARR = 5624`。ADC 时钟约 30 MHz，三通道各按 1.5 周期采样和 12.5 周期转换估算，总转换时间约为：

```text
3 * (1.5 + 12.5) / 30 MHz = 1.4 us
```

折合 180 MHz 定时器约 252 个计数。首版使用：

- `sample_guard_ticks = 360`，约 2.0 us。
- `sample_tick = ARR - sample_guard_ticks = 5264`。
- `low_side_blanking_ticks = 180`，约 1.0 us。

360 个计数为 ADC 三通道完成转换留下余量；180 个计数用于避开低侧刚导通时 SOx 的建立和开关噪声。两者都是首轮示波器验证后的可调参数，不是电机电流限值。

### 6.2 有效性公式

在当前 PWM Mode A 映射下，对每一相计算：

```text
low_side_margin_x = sample_tick - sampled_duty_x
phase_x_valid = low_side_margin_x >= low_side_blanking_ticks
```

闭环启用前必须用示波器同时观察 PWM、CH4 与 SOx，确认比较极性、计数方向和上式对应“低侧已稳定导通”。若实测极性相反，应修正映射公式，不得仅通过修改门槛掩盖错误。

### 6.3 两相选择与重构

- 三相全部有效：选低侧余量最大的两相作为直接测量，重构第三相，以保持统一的数据路径并抑制边缘样本。
- 恰好两相有效：直接使用两相，重构无效相。
- 少于两相有效：整帧无效，不进入 Clarke/Park。

重构关系为：

```text
Ia = -(Ib + Ic)
Ib = -(Ia + Ic)
Ic = -(Ia + Ib)
```

仅在三相原始样本都有效时计算原始 `Ia + Ib + Ic` 不平衡量。重构后的三相之和恒为零，不能用来证明传感器或采样质量正常。

## 7. 无效帧与 PI 行为

当少于两相有效时：

1. 不更新 Clarke/Park 输入。
2. 冻结 `id`、`iq` PI 积分器，避免无反馈积分累积。
3. 本周期保持上一有效周期的电压指令，但仍执行既有 `±2 V` 电压限幅。
4. 累加总无效帧数和连续无效帧数。
5. 连续 8 帧无效时关闭 PWM，并锁存“电流采样窗口不足”故障。

一帧重新有效后，连续无效计数清零；总计数保留供诊断。启动和模式切换必须显式清除上一模式遗留的 `sampled_duty`、无效帧计数及保持输出，防止旧状态进入新闭环。

## 8. 限流与保护

- 用户电流命令限幅：`IQ_MAX_A = 1.5 A`，正负对称。
- 速度 PI 的 `iq_ref` 输出限幅：复用 `±IQ_MAX_A`。
- 软件过流阈值：任一有效/重构相电流绝对值达到 `2.0 A`。
- 软件过流去抖：连续 4 个有效采样帧超过阈值后锁存故障，约 0.25 ms（16 kHz）。
- 电流 PI 输出限幅：首轮仍为 `±2 V`。
- 无效帧不参与过流去抖；连续无效帧由独立的 8 帧采样故障处理。

`±1.5 A` 与采样算法没有直接绑定。采样是否有效由 PWM 电压调制产生的低侧导通窗口决定，而所需电压同时受绕组电阻、电感动态项和反电动势影响：

```text
V = R * I + L * dI/dt + back-EMF
```

因此低速大电流可能压缩窗口，高速小电流也可能因反电动势压缩窗口。命令限流保护电机；有效性判定保护控制算法，两者必须分别处理。

## 9. 诊断接口

调试快照和 shell 至少提供：

- 三位相有效掩码。
- 被重构的相编号。
- A/B/C 三相低侧余量计数。
- 与样本配对的 A/B/C `sampled_duty`。
- 原始三相电流和最终重构三相电流。
- 总无效帧数、连续无效帧数、PI 冻结次数。
- 当前 `sample_tick`、消隐门槛和采样故障状态。

这些字段用于判断失败属于采样窗口不足、信号异常、PI 电压饱和还是电机能力限制。

## 10. 验证计划与验收标准

### 10.1 主机单元测试

覆盖以下情况：

1. 三相全部有效以及 A/B/C 各自无效的组合。
2. 三相占空比的六种大小排序，确认选择余量最大的两相。
3. A、B、C 三种重构公式及 KCL 结果。
4. 少于两相有效时帧无效、PI 冻结、保持输出。
5. 连续无效 8 帧锁存故障；有效帧使连续计数清零。
6. 过流连续 4 个有效帧锁存；无效帧不推进过流去抖。
7. `sampled_duty` 与 ADC 样本的上一有效 PWM 周期对齐，防止使用 `next_duty`。
8. 电流模式和速度模式的 `iq_ref` 均限制在 `±1.5 A`。

### 10.2 静态检查与构建

- 运行现有电流采样、FOC、速度环和 ISR 静态测试。
- 增加禁止 ADC 原始三相值绕过重构直接进入 Clarke/Park 的检查。
- 完整编译 AT32M412 固件，确认无新增警告。

### 10.3 示波器验证门

在闭环带载前：

1. 同时观察任一相 PWM、TMR1 CH4 触发标志和 SOx。
2. 确认 `sample_tick = 5264` 时 ADC 窗口在更新事件前完整结束。
3. 确认有效性公式判为有效时，低侧已稳定导通至少 180 个计数。
4. 扫描三相不同占空比，确认软件有效掩码与波形一致。

若这一步失败，不进入电流闭环测试，而是修正触发极性、状态对齐或门槛。

### 10.4 分阶段台架验证

第一阶段必须完成以下正反向电流点：

```text
±50 mA, ±100 mA, ±200 mA, ±500 mA
```

每个点要求：

- `iq_avg` 方向正确，稳态误差不超过 `max(20 mA, 目标值的 10%)`。
- `|id_avg| <= 100 mA`。
- 无过流、采样窗口或驱动故障。
- 不出现持续无效帧；无效总数若增长，必须能与短暂调制边界对应并且不形成连续故障。
- PWM 极性、编码器方向和实际转矩方向一致。

第二阶段在第一阶段通过后，由人工逐级测试：

```text
±0.75 A, ±1.0 A, ±1.25 A, ±1.5 A
```

出现温升异常、异常噪声、`±2 V` 长时间饱和或无效帧明显增加时，立即停止向上提升。最大能力未确认前，不自动跑满 `±1.5 A`。

第三阶段仅在 `±500 mA` 全象限电流验收通过后进行低速正反转、制动和反转的速度环测试。

实现应将纯判定/重构算法与寄存器操作分开，使窗口计算、重构、计数和保护逻辑可在主机侧穷举测试。

## 12. 风险与升级条件

- 若常用调制范围内经常少于两相有效，先复核 PWM/CH4 极性、周期对齐和消隐门槛。
- 若确认时序无误后仍持续缺少两相窗口，再升级为动态 CH4；动态方案仍不足时再考虑双触发 DMA。
- 若电流闭环在有效帧稳定的情况下仍振荡，才进入零点、增益、相序和 PI 参数的下一轮诊断。
- 若 `±1.5 A` 前出现电机温升或电压饱和，降低产品电流限幅；不能通过放宽过流阈值来强行达到目标。

## 13. 实施门禁

1. 本规格确认后，先编写逐文件实施计划和测试顺序。
2. 先写主机测试，再实现重构和保护逻辑。
3. 构建与静态测试全部通过后，才烧录进行示波器验证。
4. 示波器验证通过后，才执行低电流全象限台架测试。
5. `±500 mA` 全象限通过后，才允许扩大电流和速度环测试。
