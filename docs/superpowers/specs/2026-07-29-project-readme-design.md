# MPS MotorDriver 项目 README 设计

## 目标

为仓库主分支增加面向开源工程师和项目访客的首页 README。读者应能在几分钟内理解项目做什么、硬件由什么组成、软件已实现哪些能力、如何构建，以及去哪里查看详细设计和实机记录。

## 首页结构

README 使用“工程首页型”结构，顺序固定如下：

1. 首行使用相对路径展示 `doc/pic/V2.jpg` 实物效果图。
2. 项目标题和一句话定位。
3. 已实现的核心能力，包括有感 FOC、电流/速度/位置三环、CAN 节点、保护、标定和 LKS Scope 在线整定。
4. 硬件组成与关键控制频率。
5. 软件分层和主要目录。
6. ARM GCC/CMake 与 Keil MDK 两套构建入口。
7. 串口、CAN 和 LKS Scope 调试入口。
8. 当前完成状态与尚未完成的联调项。
9. 详细设计、调试记录和测试报告索引。

## 内容边界

- 使用中文撰写，变量名、命令和路径保留英文。
- 不复制长篇设计文档，只提供准确摘要和链接。
- 不把双节点五连杆完整机构联调描述成已经完成。
- 不承诺未经当前仓库记录支持的性能指标。
- 不写依赖特定电脑盘符的构建命令；README 内均使用仓库相对路径。
- 不增加徽章、许可证或发布包说明，因为仓库当前没有对应配置。

## 图片与排版

首个非空内容为：

```markdown
![MPS MotorDriver V2](doc/pic/V2.jpg)
```

图片之后再出现一级标题，确保打开仓库时先看到实物效果。其余内容使用短段落、列表、表格和小型目录树，避免写成论坛过程帖。

## 验证

完成 README 后检查：

1. `doc/pic/V2.jpg` 存在，Markdown 相对路径大小写一致。
2. README 提到的源码目录、工程文件和文档链接都存在。
3. CMake 命令与当前 `CMakeLists.txt`/工具链入口一致。
4. Keil 工程路径指向 `project/MDK_V5/MPS_MotorDriver.uvprojx`。
5. 当前状态描述与 `doc/调试记录.md` 及现有测试报告一致。
6. `git diff --check` 通过。
