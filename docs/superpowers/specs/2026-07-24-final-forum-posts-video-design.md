# V2 技术帖、比赛作品帖与演示视频内容设计

日期：2026-07-24

## 1. 目标

在项目收尾阶段形成三份互相配合、不过度重复的内容：

1. 一篇 V2 硬件与控制调试过程帖；
2. 一篇 MPS 机器人模块设计大赛最终作品提交帖；
3. 一份约 3 分 30 秒、低拍摄成本的横屏演示视频脚本与制作建议。

整体叙事采用以下分工：

```text
V2 技术帖：讲证据、调试过程和工程边界
比赛作品帖：讲完整作品、五连杆落地和提交材料
演示视频：用最少补拍串起项目故事并展示最终效果
```

## 2. 已确认事实与证据边界

### 2.1 可直接陈述的结果

- V2 使用 MA600A 同轴布局。
- 编码器由 TMR7 以 4 kHz 独立采样，16 kHz FOC ISR 消费已发布快照。
- 两套 V2 板的自动标定均覆盖 256 bins；已有记录的最大标定指标分别为 115 mdeg 和 60 mdeg，采集期间 spike 为 0。
- 该标定指标是内部 correction table 质量指标，不是外部高精度基准下的绝对角度误差。
- 电流环在 `Iq_ref=±50/±100/±200/±500 mA` 八点完成实测；最终权威复验中 Iq 最大偏差约 2 mA、最大 `|Id|` 约 1 mA。
- 上述电流环证据不覆盖 `|Iq|>500 mA` 和 ±1.5 A 最大能力。
- 速度环在 200 rpm_e 空载点可重复通过；±60 rpm_e 的长窗平均速度接近目标，但 4 ms 瞬时速度纹波不能稳定通过既定门槛。
- 60 rpm_e 对 7 极对电机约为 8.6 rpm_mech，不能写成超低速性能已经结案。
- 单电机位置环已完成位置、速度、电流三级级联；±5°静态误差小于 0.5°，10°/30°/s 正弦跟踪 P95 最好约为 1.329°。
- 第二套板完成电流零偏、MA600A 自动标定和本地 ±5°位置烟测；记录误差约为 0.183°和 0.238°。
- 电机侧 CAN 使用“节点预装轨迹点 + 广播 SYNC”的双节点同步方案。
- X-Track 使用独立 10 ms 硬件节拍发送单节点轨迹；已有 60 s 实测中最大 `sync_age` 为 19 ms，参考无冻结，CAN 错误计数无增长。
- 上述 CAN 实测中 10°位置指令没有在 350 ms 内达到既定幅度门槛；CAN 时序和安全通过不等于动态响应全部达标。
- 五连杆双电机硬件已经设计、打印并装配完成。

### 2.2 只能写成当前状态或待补结果的内容

- 第二套板尚未在五连杆约定机械零位写入永久 Node 2 关节记录。
- 双节点 applied sequence 一致性、同步偏差和长时间运行仍在调试。
- X-Track 尚未实际带动五连杆完成最终轨迹演示。
- 五连杆机构负载下的位置误差和最终效果尚无可引用数据。
- 最终效果图片、GIF、视频链接及轨迹误差只能在联调完成后补入。

## 3. V2 技术帖设计

### 3.1 定位与标题

标题：

> 从同轴磁编到三环闭环：V2 电机驱动板调试记录

这篇承接 V1 旁轴磁编与 V2 改版决策，不重复展开 MA600A 基础 SPI 协议。重点回答：V2 回来以后，同轴布局是否降低了传感不确定性，三环控制如何逐级跑通，CAN 联调又暴露了什么新问题。

### 3.2 章节结构

1. 开场：上一篇决定改同轴，这一篇让数据说话。
2. V2 改版与上电：同轴 MA600A、PWM 引脚和板级映射变化、两套板准备。
3. 同轴磁编：4 kHz 采样、16 kHz FOC 快照、两套板标定结果、诊断并发读 SPI 的竞态。
4. 电流环：低边电流镜、采样窗口、极性错误导致 PI 正反馈、±500 mA 八点矩阵。
5. 速度环：编码器方向归一化、测速窗口、PI 与摩擦补偿、200 rpm_e 结果和低速纹波边界。
6. 位置环：三级级联、位置与速度前馈、断流保持、静态/换向/正弦跟踪结果。
7. CAN：预装点与 SYNC、1 kHz 服务节拍、100 Hz 轨迹、无 ACK 时错误中断饿死串口、单节点 60 s 实测。
8. 第二套板与当前边界：本地三环通过，Node 2 配置和五连杆联动仍在调试。
9. AI 协作与小结：AI 负责拆解、测试和记录，硬件证据决定结论。

### 3.3 视觉素材占位

采用含义明确的占位符，不伪造图片或数据：

```text
[V2-01] V1 旁轴与 V2 同轴 PCB/机械位置对比
[V2-02] 两套 V2 驱动板与电机合照
[V2-03] MA600A 标定状态或 raw/corrected 曲线
[V2-04] 电流环 Id/Iq 波形或八点矩阵摘要
[V2-05] 速度环 200 rpm_e 与 60 rpm_e 对比
[V2-06] 位置环静态、换向和正弦跟踪结果
[V2-07] CAN 状态与 X-Track 单节点联调
[V2-08] 五连杆双电机硬件现状
```

## 4. 比赛作品帖设计

### 4.1 定位与标题

标题：

> 小型双电机关节驱动与五连杆 Demo——MPS 机器人模块设计大赛作品提交

作品帖以“从两颗小电机到双电机五连杆演示平台”为主线，满足作品简介、系统框图、器件说明、源码、视频和总结等提交要求。调试细节通过链接指向过程帖，只保留足以证明作品完成度的数据。

### 4.2 章节结构

1. 作品简介：100–200 字，交代名称、功能、双节点和五连杆应用。
2. 系统总体方案：X-Track、CAN、两个独立驱动节点、两个电机和五连杆机构。
3. MPS 器件：MP4583 电源、MP6540H 三相驱动、MA600A 同轴角度反馈。
4. 驱动板设计迭代：V1 旁轴到 V2 同轴的简要工程取舍。
5. 控制系统：16 kHz FOC、三级级联、保护和轨迹预装 + SYNC。
6. 五连杆 Demo 设计：两主动关节、连杆布局、运动范围和 3D 打印验证思路。
7. 打印与装配：打印、后处理、轴承/连杆/电机安装、板卡与线束、机械零位。
8. 联调过程：单板、单节点、第二节点、双节点和机构联调的递进路径。
9. 已完成结果：用紧凑表格汇总磁编、电流环、速度环、位置环和单节点 CAN。
10. 最终效果展示：补入五连杆动作、轨迹、误差和视频。
11. 源码、编译与使用说明：源码包、Keil/CMake、J-Link、CAN 接口和安全说明。
12. AI 协作、项目总结与改进方向。

### 4.3 最终联调占位

作品帖正文先完整写成可发布草稿，仅保留这些最终占位：

```text
[FINAL-01] 五连杆最终全景照片
[FINAL-02] X-Track 控制界面或轨迹截图
[FINAL-03] 双节点 applied sequence / sync age / fault 摘要
[FINAL-04] 五连杆最终动作 GIF 或连续照片
[FINAL-05] 机构负载下轨迹误差或定性结果
[FINAL-06] 最终演示视频链接
[FINAL-07] 源码压缩包或公开仓库链接

```

如果最终联调未达到预期，仍按真实结果描述能完成的动作、限制和安全状态，不把“硬件已搭建”扩写成“完整轨迹已通过”。

## 5. 演示视频设计

### 5.1 成片规格

```text
时长：约 3 分 30 秒，可在 3 分 20 秒至 4 分钟内调整
画面：16:9 横屏，建议 1080p/30 fps
声音：开场同期声，其余以后期人声配音为主
人物：开头露脸约 10 秒，结尾可复用同一机位
字幕：思源黑体或其他明确可用字体
音乐：可不使用；如使用，只选有明确授权的低音量背景音乐
```

### 5.2 时间轴

| 时间 | 内容 | 主要素材 |
| --- | --- | --- |
| 0:00–0:12 | 露脸自我介绍 | 同一固定机位，人物与五连杆同框 |
| 0:12–0:30 | 作品整体与项目缘起 | 桌面全景、成品特写 |
| 0:30–0:55 | 系统与 MPS 器件 | 系统框图、V1/V2 图片、器件标注 |
| 0:55–1:20 | V2 同轴磁编与双驱动板 | PCB/电机局部桌拍 |
| 1:20–2:00 | 三环控制与 CAN | 既有波形、日志、X-Track/CAN 截图 |
| 2:00–2:35 | 五连杆设计、打印和装配 | CAD、切片、打印件与装配照片 |
| 2:35–3:15 | 最终五连杆运行效果 | 一段 30–60 秒固定机位素材，后期裁切复用 |
| 3:15–3:30 | 总结与收尾 | 人物或作品定格 |

### 5.3 最低补拍清单

1. 露脸开场和结尾同机位一次录完，约 25 秒；
2. 桌面整体固定镜头约 15 秒；
3. 驱动板、MA600A、MP6540H 等局部各约 5 秒，总计约 20 秒；
4. 手动活动五连杆或上电准备约 10 秒；
5. 最终运行固定机位连续拍摄 30–60 秒。

补拍原始视频总量可控制在 3 分钟以内。CAD、PCB、打印过程、波形、串口日志和系统框图使用现有静态素材，通过轻微缩放和横移形成画面变化。

### 5.4 制作原则

- 现场不边操作边背长词；先拍干净画面，再录旁白。
- 最终动作先完整固定机位记录，确保技术证据存在，再考虑特写。
- 技术数字只保留最能说明问题的 3–5 个，避免视频变成测试报告朗读。
- 画面中出现电机运行时，尽量同时保留整机、线束和安全供电状态。
- 失败或未完成部分不需要专门渲染；用一句“当前仍在优化双节点机构联动”交代即可。

## 6. 正式成稿要求

- 使用第一人称中文工程叙事，语气实用、克制，保留少量调试幽默。
- 每个结论都能追溯到调试记录、测试报告或用户补充事实。
- 已确认结果、推断和待验证内容明确分开。
- V2 技术帖不写成产品宣传稿，保留低边电流极性、低速纹波和 CAN 错误中断等真实问题。
- 比赛作品帖不重复整篇技术调试，只汇总关键数据并链接过程帖。
- 视频旁白与帖子采用一致的数据口径。
- 正式交付包括两篇 Markdown 草稿、一份按秒脚本、补拍清单和剪辑建议。

## 7. 完成验收

正式内容完成时检查：

1. 两篇帖子章节齐全，所有缺失素材都有唯一占位编号；
2. 不出现未经证据支持的双节点同步或五连杆最终效果结论；
3. 比赛作品帖包含简介、系统框图说明、MPS 器件、源码、视频和总结入口；
4. 视频脚本达到 3 分钟以上，包含露脸自我介绍、人声介绍、必选物料和实物演示；
5. 最低补拍清单可以由一台手机和一个固定机位完成；
6. 三份内容中的关键参数和项目状态一致。
